# BodyBuilder — Download Instructions

**Version 1.2.1 · macOS**

---

## Which file should I download?

There are two versions of BodyBuilder available. You only need to download **one**.

| File | Who it's for |
|---|---|
| `BodyBuilder-1.2.1-arm64.dmg` | **Apple Silicon Macs** — any Mac with an M1, M2, M3, or M4 chip (most Macs made from late 2020 onwards) |
| `BodyBuilder-1.2.1-x86_64.dmg` | **Intel Macs** — older Macs made before late 2020 |

**Not sure which one you have?** Follow the steps below — it takes less than 30 seconds.

---

## How to check which Mac you have

1. Click the **Apple logo** () in the top-left corner of your screen.
2. Click **"About This Mac"**.
3. A window opens. Look for the **Chip** or **Processor** line:

| What you see | Download this file |
|---|---|
| **Apple M1**, **Apple M2**, **Apple M3**, **Apple M4** (or any M-number) | `BodyBuilder-1.2.1-**arm64**.dmg` |
| **Intel Core i5**, **Intel Core i7**, **Intel Core i9**, **Intel Xeon** (or any Intel) | `BodyBuilder-1.2.1-**x86_64**.dmg` |

> **Quick rule of thumb:** If your Mac was bought in 2021 or later, it almost certainly has an Apple chip. If it was bought in 2019 or earlier, it almost certainly has an Intel chip. If you bought it in 2020, check the label above to be sure.

## Installing BodyBuilder

Once you've downloaded the correct `.dmg` file:

1. Open your **Downloads** folder and **double-click** the `.dmg` file.
2. A window opens showing the BodyBuilder icon and an **Applications** folder shortcut. **Drag BodyBuilder into the Applications folder.**
3. Close the window. You can eject the disk image by clicking the ▲ button next to "BodyBuilder" in the Finder sidebar.
4. Open **Finder → Applications** and double-click **BodyBuilder** to launch it.

---

## First launch — macOS security warning

The first time you open BodyBuilder, macOS may show a message like:

> *"BodyBuilder cannot be opened because it is from an unidentified developer."*

**This is normal.** BodyBuilder is not distributed through the Mac App Store, so macOS shows this warning once. The app is safe to open.

**How to get past this warning:**

1. Do **not** double-click the app.
2. Instead, **right-click** (or hold **Control** and click once) on **BodyBuilder** in your Applications folder.
3. Choose **"Open"** from the menu.
4. A new dialog appears asking if you're sure. Click **"Open"**.

After this one-time step, BodyBuilder will open normally every time — you won't see this warning again.

> **If right-clicking doesn't work:** Go to **System Settings → Privacy & Security**, scroll to the bottom, and look for a message about BodyBuilder being blocked. Click **"Open Anyway"** and enter your Mac password if asked.

## What happens when BodyBuilder opens

- A small window may flash briefly while the app starts — this is normal and closes on its own.
- Your web browser opens automatically showing the BodyBuilder interface.
- If the browser doesn't open, go to: **http://localhost:8000**
